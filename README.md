# 我的家乡 3D

一个可以在浏览器里"走进去"的豫南乡村。

> 🌐 在线试玩：<https://l1ha.github.io/MyTown/>　·　源码：<https://github.com/l1Ha/MyTown>

豫南淮河岸边的村庄、砖瓦房与土坯老屋、堂屋里的八仙桌、晒场的石磙、麦田与秧田、
淮河大堤与渡口、逢集的摊位、四季与昼夜、以及能和你搭话的乡亲。

> 所有画面、地形、房屋、庄稼、树木、天空、云雨与声音**全部由代码现场生成**
> ——没有一张外部图片，没有一个外部音频文件。整个项目就是这份源码。

## 一、怎么玩

### 1. 最简单：直接双击

双击 `index.html` 就能玩（使用的是传统 `<script>` 标签，不需要构建、不需要联网）。

### 2. 推荐：本地小服务器

如果浏览器对本地文件限制较多（个别浏览器会禁止读写本地存储），可以用任意静态服务器：

```bash
# 在本目录下执行其一
python -m http.server 8080
npx serve .
```

然后打开 <http://localhost:8080/>。

> 首次进入会现场生成整个世界（约 1～4 秒），载入画面会显示进度。

### 3. 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` | 前后左右走动 |
| `Shift` | 奔跑 |
| `空格` | 跳跃（飞行模式下为上升） |
| `Ctrl` / `C` | 蹲下（飞行模式下为下降） |
| 鼠标 | 转动视角（点击画面锁定鼠标，`Esc` 解锁） |
| `E` / 鼠标左键 | **交互**：看地点、聊村民、收庄稼、拾信物、上渡船 |
| `F` | 切换 **飞行观景**（鸟瞰全村） |
| `P` | **拍照模式**（换滤镜、调焦距、空格存 PNG） |
| `M` / `J` | 村庄地图 / 家乡图鉴 |
| `H` | 隐藏或显示界面 |
| `[` / `]` | 减慢 / 加快时间 |
| `Esc` | 暂停菜单（画质、季节、天气、时间、音量…） |

### 手机 / 触屏

暂停菜单里的 **手机模式** 可选「自动 / 开启 / 关闭」，触屏设备默认自动开启；
游戏里点快捷栏的 **手机** 也可一键切换。触屏操作：

* 左下 **虚拟摇杆** 走路；
* 屏幕右侧 **拖动** 转视角；
* 右下按钮：**交互 / 跳 / 跑 / 蹲 / 飞行**；
* 右上 **☰** 打开暂停菜单（地图、图鉴、拍照、设置都在里面）。

### 4. 玩法目标

菜单里的 6 个探索任务会引着你把村子走一遍：

1. **认识家乡** —— 走近并查看 5 处地点
2. **寻访信物** —— 找到 8 件文化信物（会发光的小物件）
3. **农事体验** —— 在田里干活 3 次（麦田、油菜、菜地都能动手）
4. **乡音乡情** —— 跟 5 位乡亲聊天
5. **淮河记忆** —— 登上淮河大堤，再坐渡船到北岸
6. **四季任庄** —— 看看春、夏、秋、冬的家乡

每个地点、每件信物、每位乡亲都会往 **家乡图鉴（J）** 里记录一条内容。

## 二、里面有什么

* **地形**：1000m × 1000m 程序化地形。淮河、淮河大堤、河滩芦苇、西部丘陵与杨树林、
  水塘与藕塘、灌溉水渠、田间土路与水泥乡道。
* **民居**：土坯老屋、红砖瓦房、两层小楼，带院墙、门楼、楹联、堂屋陈设
  （八仙桌、长条几、中堂、织布机、老座钟）；灶屋、猪圈、鸡舍、柴垛、
  压水井、石磨、水缸、晾衣绳、玉米架、狗窝。
* **公共建筑**：村委会（大喇叭、旗杆、村务公开栏）、村小学（操场、篮球架、单杠）、
  小卖部（货架、冰柜、雨棚）、卫生室、碾米房、村水塔、电灌站、
  任氏宗祠、土地庙、老井、村口石碑与大槐树、逢集摊位。
* **农田**：125 块田地，水稻田（带田埂与秧水）、麦田、玉米、油菜、菜园、
  塑料大棚、机井泵房、水渠、稻草人；以及打谷场（晒场：石磙、粮堆、草垛、
  拖拉机、三轮车、板车、簸箕）。
* **人**：20 位村民 —— 下棋的爷爷、插秧的大姐、碾米的老李、张船夫、王老师、
  小卖部老板娘、赤脚医生……每个人都有家乡话的对白。
* **动物**：鸡、鸭、狗、猪、水牛、羊、猫。
* **天气与时间**：完整的昼夜循环（日出、正午、日落、星空、月光）、
  云、晴/多云/阴/小雨/雷阵雨/雪、季节（春油菜花与插秧 / 夏绿稻蝉鸣 /
  秋金黄稻浪 / 冬雪落平原）。
* **声音**：风声、水声、鸟叫、蝉鸣、蛙声、鸡叫、狗吠、脚步声（草地/泥地/水泥不同）、
  过渡船的水声，以及一段五声音阶的生成式小调——全部是 WebAudio 实时合成。

## 三、文件结构

```
index.html              界面结构 + 脚本载入
styles.css              界面样式（宣纸、墨色、朱红）
vendor/three/three.min.js   Three.js r160（本地内置，离线可用）
src/
  main.js               引导：载入进度、错误提示、启动
  core/
    util.js             数学 / 可复现随机数 / 噪声 / 静态网格合并(MT.Batch)
    textures.js         全部程序化贴图与材质（含中文文字贴图、匾额、石碑）
    audio.js            WebAudio 合成音效与环境音
    input.js            键盘/鼠标/指针锁定
    hud.js              HUD、小地图、罗盘、图鉴、菜单、大地图
  world/
    sky.js              天空穹顶、日月、星空、云、飞鸟、雨雪、雾、昼夜与天气
    terrain.js          地形高度场、淮河、大堤、道路网络、水面
    buildings.js        建筑工厂（屋顶/门窗/院墙/门楼/附属房/可进入房间）+ 自动碰撞体
    props.js            小物件、农具、车辆、家禽家畜（含逐帧动画）
    public.js           公共建筑与地标（祠堂、土地庙、学校、渡口…）
    vegetation.js       树木/草丛/芦苇/荷叶（按树种实例化，四季变色）
    farm.js             田地规划、作物、田埂、水渠、大棚、稻草人、打谷场
    village.js          总装：把上面的一切摆到地球上，并登记地点与信物
  game/
    culture.js          ★ 文化图鉴词条、信物、任务、乡音对白（内容都在这里改）
    npc.js              村民（低多边形人物、行走、对话）
    player.js           第一人称控制器（碰撞、涉水、飞行、拍照）
    game.js             主程序：装配、交互、任务、存档、设置、主循环
```

### 想改内容？只需要改两个文件

* `src/game/culture.js` —— **所有文字内容**：地名、图鉴词条、任务、村民对白。
  想写自己村的真实典故，直接改这里即可（每个词条的 `id` 与 `village.js` 里的地点一一对应）。
* `src/world/village.js` —— **想加/挪一栋房子、一口井、一条路**，
  改 `build()` 里的坐标数组就能看到效果（坐标单位是米，`+X` 东，`-Z` 北）。

改完代码后如果浏览器还显示旧画面，在地址栏的网址后面加 `?v=2`（`?v=3`…）强制刷新脚本缓存。

## 四、技术说明

* **Three.js r160**（UMD 版，本地内置）+ 原生 JavaScript，无框架、无构建步骤。
* 地形：解析式高度场（值噪声 fbm + 河流/大堤/村落整平特征）→ 生成 257×257 网格，
  玩家行走时用同一份高度栅格做双线性采样，保证脚下与画面完全一致。
* 碰撞：世界搭好后**自动**从网格包围盒生成 1100+ 个 AABB（并排除屋顶、门窗、地板、
  小物件与大尺度的田面/道路），玩家用竖直圆柱体做分轴推出。
* 性能：同材质的静态网格自动**合并**（约 4550 个网格 → 370 个绘制批次）；
  树木/庄稼/草丛/芦苇用 `InstancedMesh`；远距离的动物与旗帜动画自动降频。
* 贴图：全部用 `<canvas>` 现场绘制（砖纹、瓦当、夯土、树皮、木门、玻璃、稻草、
  麦穗、稻穗、玉米、油菜花、芦苇、水波法线、云、雪、汉字匾额……）。
* 光照：太阳/月亮方向光 + 半球光 + 环境光，按时间关键帧插值，ACES 色调映射，
  2048 阴影贴图；高画质下用 `PMREMGenerator` 把天空烘成环境贴图，水面才有天光反射。
* 存档：`localStorage`（自动每 2 分钟 + 关闭页面时保存）。

### 画质与性能

暂停菜单里可以切换 **低 / 中 / 高 / 极高**（切换后重新载入页面生效）：

| 画质 | 特点 |
| --- | --- |
| 低 | 关阴影、关细节、植被减半、像素比 1.0（老笔记本可用） |
| 中 | 关阴影，植被中等 |
| 高 | 阴影 + 环境贴图 + 全量植被（推荐） |
| 极高 | 阴影 + 环境贴图 + 2× 像素比（高分屏） |
